Drop transparent-background PNG cut-outs here, named `<name>.png` (e.g. `maya.png`,
`vanessa.png`) or `<name>_<mood>.png` (e.g. `maya_shocked.png`). `thumbnail.py`
puts one of them on every long-form thumbnail; with no files here it draws a
cartoon face instead. Moods it asks for: shocked, angry, sad, smug.
